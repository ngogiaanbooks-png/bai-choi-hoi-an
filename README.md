# Học liệu Bài Chòi Hội An

Website song ngữ (Việt và Anh) của bộ học liệu điện tử truyền dạy nghệ thuật Bài Chòi Hội An: 36 video, 30 quân bài số hóa và 10 đồ họa thông tin. Website dựng bằng Vite, React và framer-motion.

## Chạy trên máy

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # build ra thư mục dist/
npm run preview   # http://localhost:4173
```

Mỗi lần đẩy lên nhánh `main`, GitHub Actions tự build và đăng website lên GitHub Pages.

## Tài liệu

- `GUIDELINES.md`: nguyên tắc dự án, cấu trúc mã, các đường dẫn, cách thay media thật.
- `CONTENT-TODO.md`: nội dung cần khách xác nhận.
- `TRANSLATION-TODO.md`: bản tiếng Anh cần duyệt.
